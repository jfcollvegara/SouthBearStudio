# Cabecera audiovisual — cuatro vídeos

Los cuatro archivos `1.mp4`, `2.mp4`, `3.mp4` y `4.mp4` deben subirse a esta carpeta, conservando los nombres. La página `src/pages/servicios/audiovisual.astro` ya los reproduce en ese orden, en bucle, silenciados y adaptados a 2,35:1 mediante `object-fit: cover` (recorte simétrico por arriba y abajo, sin deformación ni cambio de resolución).

Las versiones web optimizadas mantienen las dimensiones originales y tienen un tamaño adecuado para GitHub y Cloudflare Pages. Mientras falten archivos, se ven los recuadros grises provisionales.
